# App 与后台连接

当前 App 的接口地址为 `https://mistoto.cc.cd/luiyo/api.php`，由 Info.plist 的 `LUIYO_AUTH_URL` 配置。仓库提交不代表线上部署；后台升级步骤见 [UPGRADE-BUILD22.md](UPGRADE-BUILD22.md)。

Build 22 自动登记已授权和未授权设备，前台每 30 秒发送心跳，超过 90 秒视为离线。设备登记与授权分开，未授权仍只能浏览。原有卡密和 Keychain 令牌保留，启动、回到前台及使用期间约每 5 分钟验证权限。

UDID 优先读取签名时附带的描述文件。仅当 `ProvisionedDevices` 含一个唯一号码时上报，并显示“签名文件提供（未校验）”；多台设备、企业签名或没有设备列表时不猜测。手动获取为可选操作，已授权和未授权都可使用，不影响已有授权。

本次增加展示和信息采集，没有强制硬件绑定。签名文件的设备名单不能视为当前硬件证明，描述文件关联也不等同 App Attest。用户不必为了继续使用已有授权而获取 UDID。

签名文件解析须签名安装后验证。IPA 未签名；没有做自动模拟器验证，保留编译和代码/后台回归检查。
